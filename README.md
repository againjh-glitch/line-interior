# 라인 인테리어 견적 계산기

아파트별 **기본 견적서**를 고르고, 집마다 다른 **특이사항**만 더해서 견적을 만든 뒤,
**고객에게 링크로 바로 보내는** 웹 견적 계산기입니다.
빌드 없이 브라우저에서 바로 동작합니다 (GitHub Pages로 배포).

> 바탕: 남편분이 만든 계산기([gabiplay-creator/line](https://github.com/gabiplay-creator/line))에
> 아파트별 기본 견적서 · 특이사항 · 고객 공유 기능을 더한 버전입니다. 기존 일반 견적·양우아파트 화면도 그대로 들어 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📋 아파트별 기본 견적서 | 기존 풀공사 견적 26건에서 공정별 중간값으로 뽑은 기본 구성 5종 — 양우 32평, SK뷰 32평, 중흥 29평, 주공 23평, 그 외 30평대. 안 하는 항목은 체크를 풀면 빠지고, 금액은 칸을 눌러 바로 고침 |
| ➕ 선택 옵션 | 샷시 전체 교체, 천장 평탄화, 중문, 신발장 등 가끔 들어가는 항목 |
| ⚠️ 특이사항 | 누수·방수, 천장·벽체 보강, 구조변경·확장, 설비·전기, 감액 등 42개 현장 조건 목록 (참고 단가 포함). 직접 입력도 가능하고, 자주 쓰는 항목은 목록에 저장 |
| 📤 고객에게 공유 | **저장하면 바로** 고객용 링크가 만들어지고 문자(고객 번호 자동 입력)·카카오톡 공유·복사 버튼이 뜸. 고객 화면에는 **품명·내용과 공정별 총 견적가만** 보임 (줄별 금액은 링크에도 담지 않음, 인쇄·엑셀 상세 견적서도 동일) (수정 불가, 인쇄·PDF 저장 가능) |
| 🔗 일반 공유 | 가족·직원용 내부 확인 링크. 기존 견적 범위·포함 빈도·비고까지 보이고 「✏️ 계산기에서 열어 수정」으로 이어서 작업 가능. 고객 연락처는 담기지 않음 |
| 🧮 내역으로 계산 | 금액 줄 옆 🧮 → 통비용을 자재(업체 단가표에서 고르기)·부자재·인건비(품 단가×품 수, 직접 입력, 기본 35만·마지막 값 기억)·기타로 풀어서 원가×마진으로 다시 계산. 문짝 교체·몰딩은 구성표 미리 채움. **그 공정 관련 자재만** 목록으로 보여주고(예: 거실 욕실 › 타일 → 욕실 자재·타일공·도기 세팅·방수 등 지난 견적 단가) 「전체 자재 보기」로 전체 목록. 계산 결과는 원가·상세내역 칸에도 들어감 |
| 🔒 원가 · 상세내역 | 엑셀 견적서처럼 줄마다 **원가**와 **상세내역**(예: 2명300+6, 목수 6품) 칸. 기존 엑셀 「원가·상세내역」 열에서 가져와 미리 채움 (원가가 다른 줄에 몰려 적힌 공정은 비우고 「지난 원가」 메모로). 총 견적가 칸 아래에 공정 원가 합·마진, 표 아래에 예상 이익. 고객 공유·인쇄에는 안 나가고 일반 공유 편집 링크에만 담김 |
| 🧮 가구 사이즈로 계산 | 기본 견적서 「가구」 칸의 버튼 → 주방가구 길이·상판·붙박이장 폭 등을 넣으면 코렉스 퍼니처 예상 원가(업체 견적 19장 기준, 평균 오차 약 3%) × 마진 1.12배로 가구 줄을 자동으로 채움. 업체 원가는 일반 공유 비고에만 보임 |
| 📒 업체 단가표 | 바닥재(LX·동화·구정·대진 등)·바닥 철거·샌딩(최하 20만원 자동 적용)·도배·문/몰딩·목공 자재·부자재·욕실·탄성·중문 업체 단가 284개를 공정별로 보고 검색. ＋넣기로 수량·마진을 넣어 해당 공정에 줄 추가 (바닥재는 「바닥재」 줄 바꾸기). 부가세 포함 단가는 1.1로 나눠 계산. 업체 연락처는 공개 사이트에 넣지 않음 |
| 🧩 공통 항목 추출 | 저장된 견적 여러 개를 골라, 공통으로 들어간 항목만 모아 새 기본 견적서로 저장 |
| 🛁 욕실 자재 견적서 | `bath.html` — 업체 종이 견적서와 **똑같은 양식**(1~27번, 8~15·26번은 「본드/ 압착/ 백시멘/ 에폭시/」처럼 한 줄 안 칸)에 제품명·수량만 넣으면 **지난 주문 단가**가 들어가고(엑셀 「욕실 단가 (2)·(3)」 634건, 자재 250종), 엑셀 「욕실 단가 (3)」 모양의 **자재 주문서**가 자동으로 만들어짐. 세트(양변기·세면기·에폭시·수전)는 부속까지 풀어서 주문. 엑셀 붙여넣기용 복사 / 엑셀 파일 저장 / 인쇄. 「단가 이력」 탭에서 자재별 최근·최저·최고·현장별 단가 검색. 새로 넣은 단가는 「내 단가」로 기억. |
| 🧾 현장 자재 요청 | `bath.html#req` — 현장에 붙일 **빈 「현장 자재 요청서」 A4 인쇄**(날짜·이름·사용 장소·품명·규격·수량·비고·주문✔). 담당자들이 적은 종이를 같은 칸 그대로 옮겨 적으면 업체 단가표·욕실 단가에서 단가가 들어가고, 「자재 주문서」 탭에 **업체 견적서 형식**(No·품명·규격·단위·수량·단가·금액·부가세·적요)으로 정리. 현장명·주소·저장은 욕실 견적서와 같이 |
| 📷 사진으로 채우기 | 견적서·현장 요청 탭의 「📷 사진으로 채우기」 — 손글씨 견적서(1~27번 양식)나 현장 자재 요청서·메모 사진을 올리면 **Claude API**가 읽어서 칸을 채움 (API 키는 그 브라우저에만 저장, 사진은 Anthropic으로만 전송). 키가 없으면 Claude 채팅에서 받은 **채우기 링크**(`bath.html#fill=…`)를 누르거나 붙여넣기. 칸 아래 📷 에 손글씨 원문이 남고, ↩ 되돌리기 가능 |
| 📤 업체 단가 요청 | 욕실 견적서의 「📤 여기가 우리집에 단가 요청」 → 제품명·규격·수량·비고만 담은 링크(`bath-quote.html#q=…`, **단가는 안 보냄**)를 문자·카톡으로 보냄. 업체가 단가를 넣고 보내기 → 회신 링크(`bath.html#reply=…`)를 열면 단가가 들어가고 **지난 단가 대비 ▲오름 / ▼내림 / 신규** 표시, 합계 차이·변동 목록. 기입 안 된 칸은 옅은 회색 |
| ⬇⬆ 백업 | 견적·템플릿을 파일 하나로 내보내고 다른 기기에서 가져오기 |

## 사용 순서 (엑셀 견적서와 같은 화면)

1. 사이트를 열면 엑셀처럼 생긴 **기본 견적서 시트**가 나옵니다. 위쪽 **탭**에서 아파트를 고르세요 (목록에 없으면 「그 외 아파트」).
2. 기본 공사 표는 **상세 견적가**(줄마다 따로 금액이 있을 때)와 **총 견적가**(공정 합계, 고객에게 보이는 금액)로 나뉩니다. 오른쪽 갈색 머리의 **원가 🔒 · 상세내역 🔒** 칸은 내부용입니다.
3. **노란 칸**에 입력합니다: 고객 정보, 기본 금액(파란 글씨), 적용(O/X), 특이사항 수량, 할인, 이윤율, 계약금 비율.
3. 안 하는 항목은 **적용 칸을 X**로 → 회색 취소선으로 바뀌고 금액에서 빠집니다. 공정 맨 윗줄을 X로 하면 그 공정 전체가 빠집니다.
4. **선택 옵션**은 적용 칸을 O로 바꾸면 들어갑니다 (샷시 전체 교체 등).
5. **특이사항**은 자주 나오는 8개가 미리 있어 수량만 넣으면 됩니다. 다른 항목은 「+ 줄 추가」 후 목록에서 고르면 단가·단위가 자동으로 들어옵니다.
6. **💾 저장** → 바로 뜨는 「고객에게 공유」 창에서 문자 또는 카카오톡으로 전송. 가족·직원에게는 **🔗 일반 공유**.
7. 예전 방식(항목을 하나씩 고르는 계산기)은 시트 위 「🧮 일반 견적 계산기로」에서 쓸 수 있습니다.

## 고객용 링크는 어떻게 동작하나요

- 서버가 없습니다. 견적 내용(고객명·주소·항목·금액)이 링크 `view.html#q=…` 안에 압축되어 들어갑니다.
- `#` 뒤 내용은 인터넷으로 전송되지 않고, 링크를 연 사람의 브라우저에서만 풀립니다.
- **고객 연락처는 링크에 넣지 않습니다.** 내부 참고 정보(기존 견적 범위, 다른 세대 사례 등)도 들어가지 않습니다.
- 링크를 가진 사람은 누구나 그 견적서를 볼 수 있으니, 고객 본인에게만 보내세요.
- 견적을 고치면 링크를 다시 보내야 합니다 (예전 링크는 예전 내용 그대로).
- 문자 보내기 버튼은 휴대폰 문자 앱을 내용이 채워진 상태로 엽니다. 전송 버튼은 직접 눌러야 합니다.

## 데이터 저장

- 저장한 견적·템플릿은 **이 브라우저(localStorage)에만** 저장됩니다. 다른 기기에서는 📂 불러오기 → **백업 내보내기/가져오기**로 옮기세요.
- 브라우저 기록을 지우면 저장된 견적도 지워지니, 가끔 백업 파일을 받아두세요.

## 금액·업체 정보 고치기

| 바꿀 것 | 파일 |
|---|---|
| 아파트별 기본 견적서 금액·항목, 특이사항 목록 단가 | `tpl-data.js` |
| 싱크대·붙박이장 업체 단가, 마진 배율 | `furniture.js` 맨 위 `FURN_ROWS`, `FURN_MULT_DEFAULT` |
| 업체 단가표 (바닥재·도배·문 등) | `vendor-data.js` · 넣을 공정·마진 기본값은 `vendor.js` 맨 위 |
| 내역 계산 구성표 (문짝·몰딩), 목수 품 기본 단가 | `breakdown.js` 맨 위 `BD_PRESETS`, `BD_LABOR_DEFAULT` |
| 일반 견적 화면 항목·단가 | `data.js` |
| 고객용 견적서의 업체명·등록번호·연락처 | `share.js` 맨 위 `COMPANY` |
| 계산기 화면의 업체 정보 | `index.html` 견적서 표 |
| 욕실 자재 목록·지난 단가·세트·견적서 줄 | `bath-data.js` (`BATH_ITEMS`, `BATH_SETS`, `BATH_LINES`) |
| 처음 열 때 화면 (기본 견적서 / 일반 견적) | `tpl.js` 맨 위 `START_MODE` |

## GitHub Pages 켜기

1. 이 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, 폴더 **/ (root)** → Save
3. 1~2분 뒤 `https://againjh-glitch.github.io/line-interior/` 에서 열립니다.

## 파일 구성

```
index.html    계산기 화면
style.css     화면 스타일
data.js       일반 견적 항목·단가
tpl-data.js   아파트별 기본 견적서 + 특이사항 목록 (기존 견적 26건 기준)
app.js        계산·견적서 출력·엑셀·저장
tpl.js        기본 견적서 · 특이사항 · 공통 항목 추출 · 백업
sheet.js      엑셀 견적서와 같은 모양의 작업 화면
furniture.js  싱크대·붙박이장 사이즈로 예상 견적
vendor-data.js 업체 단가표 데이터
vendor.js     업체 단가표 보기·견적에 넣기
breakdown.js  통비용 줄을 자재·인건비 내역으로 계산
share.js      고객용 링크 압축/해제 + 업체 정보
send.js       고객에게 공유 / 일반 공유 창
view.html     고객이 보는 견적서 페이지
bath-quote.html 업체(여기가 우리집)가 단가를 넣는 견적 요청 화면 (bath-quote.js)
bath.html     욕실 자재 견적서 → 자재 주문서 (bath.js · bath.css · bath-data.js · 사진 읽기 bath-photo.js)
```
